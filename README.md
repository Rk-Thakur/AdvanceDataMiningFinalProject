# Wineinformatics: Predicting 90+ Wines from Sensory Reviews

A data mining project that predicts whether a wine scores **90 points or higher** from the keywords in its
Wine Spectator tasting note. Three classifiers are compared — **Naive Bayes**, **Decision Tree (depth 5–9)**
and **Support Vector Machine** — and the results are presented as figures, tables and an interactive dashboard.

**Live dashboard:** https://rk-thakur.github.io/AdvanceDataMiningFinalProject/

## Dataset

`Full Wine Data.xlsx` — 1,010 wines, each described by **305 binary attributes** from the Computational Wine
Wheel (1 = the keyword appears in the review, 0 = it does not).

| | Wines | 90+ (label 1) | Below 90 (label 0) |
|---|---|---|---|
| Full data | 1,010 | 511 | 499 |
| Training (80%) | 808 | 409 | 399 |
| Testing (20%) | 202 | 102 | 100 |

The split is stratified (same 90+/90- mix in both sets) with random seed 42, so results are reproducible.
Every model is also evaluated with **5-fold cross-validation** on all 1,010 wines.

## Methods

| Model | Details |
|---|---|
| **Naive Bayes** | Bernoulli Naive Bayes **implemented from scratch** with Laplace smoothing (α = 1). Verified to match scikit-learn's `BernoulliNB`. |
| **Decision Tree** | Entropy / information gain (ID3/C4.5 criterion), maximum depth 5, 6, 7, 8 and 9. |
| **SVM** | Linear kernel, C = 1 — the same model SVM-light trains by default. Training/testing files are also exported in SVM-light format. |

Evaluation follows the course slides: confusion matrix (TP, FP, FN, TN), accuracy, precision,
recall (sensitivity), specificity, F1-score, ROC AUC and 5-fold cross-validation.

## Results

| Model | Test accuracy | Precision | Recall | Specificity | F1 | AUC | 5-fold CV |
|---|---|---|---|---|---|---|---|
| **Naive Bayes** | **87.13%** | **93.18%** | 80.39% | **94.00%** | **86.32%** | **0.944** | **87.82% ± 1.35%** |
| Decision Tree (depth 9) | 72.77% | 82.19% | 58.82% | 87.00% | 68.57% | 0.740 | 78.32% ± 3.09% |
| SVM (linear) | 86.63% | 89.47% | **83.33%** | 90.00% | 86.29% | 0.924 | 86.53% ± 3.43% |

Confusion matrices on the 202 test wines:

| Model | TP | FP | FN | TN |
|---|---|---|---|---|
| Naive Bayes | 82 | 6 | 20 | 94 |
| Decision Tree (depth 9) | 60 | 13 | 42 | 87 |
| SVM (linear) | 85 | 10 | 17 | 90 |

Decision tree by depth (test accuracy): depth 5 = 70.30%, 6 = 71.78%, 7 = 74.26%, 8 = 75.25%, 9 = 72.77%.
Depth 9 has the best cross-validation accuracy; training accuracy keeps rising with depth (77.1% → 86.0%),
a sign of overfitting.

**Keywords that mark 90+ wines** (agreed on by Naive Bayes, SVM and the decision tree):
APRICOT, BEAUTY, EXPRESSIVE, LONG, LONG FINISH. Words such as LIGHT-BODIED, FRESH and simple fruit
notes are typical of wines rated below 90.

## Run with Docker (easiest)

Requires [Docker Desktop](https://www.docker.com/products/docker-desktop/). From the project folder:

```bash
./run_dashboard.sh
```

This builds the image (installs the libraries, trains all models and generates the results inside the
container), starts the dashboard and opens it in your browser at `http://localhost:8000`
(the next free port is used if 8000 is taken). Stop it with `docker stop wine-dashboard`.

Without the script (e.g. on Windows):

```bash
docker build -t wine-dashboard .
docker run --rm -p 8000:8000 wine-dashboard
```

then open http://localhost:8000 in your browser.

## How to run (without Docker)

Requires **Python 3.9+**. Run the commands from the project folder.

**1. Create a virtual environment and install the libraries** (first time only)

macOS / Linux:
```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

Windows:
```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

**2. Train the models and generate all results** (about a minute)

```bash
.venv/bin/python wine_classification.py
.venv/bin/python export_interactive_data.py
```

On Windows use `.venv\Scripts\python` instead of `.venv/bin/python`.
The second script rebuilds the same models and checks that every prediction matches the first script's output.

**3. View the results**

- Figures and tables: open the `results/` folder (`results/RESULTS_SUMMARY.md` summarises everything).
- Interactive dashboard: open `dashboard/index.html` in any browser — no internet or server needed.

```bash
open dashboard/index.html
```

## Interactive dashboard

The dashboard presents every result from Section IV and lets you explore them:

- **Depth slider** — choose a decision-tree depth (5–9); all tree metrics and the confusion matrix update.
- **Threshold explorer** — move the Naive Bayes / SVM decision threshold and watch TP, FP, FN and TN trade off on the confusion matrix and ROC curve.
- **Predict a wine** — load a test wine, paste a tasting note or pick keywords; all three models predict instantly and explain why.
- **Model toggles and metric picker** in the comparison section.
- **Laplace α selector** (Naive Bayes) and **kernel / C selector** (SVM).
- **Linked keywords** — click any keyword to highlight it in every chart; filter keyword rankings by minimum number of reviews.
- Hover tooltips, data tables under every chart, light/dark theme, animated transitions, mobile layout.

## Running SVM-light (optional)

The original `svm_learn.exe` / `svm_classify.exe` (in `course_materials/SVM (1).rar`) only run on Windows.
The project uses the equivalent linear SVM from scikit-learn, and exports the data so SVM-light can be run as well:

```bat
svm_learn.exe results\svm_light\wine_train.txt model.txt
svm_classify.exe results\svm_light\wine_test.txt model.txt svm_output.txt
```
